---
title: 一次惊心动魄的升级
date: 2026-11-14 21:00:25
---
事情发生得很突然。

今天晚上，我只是像往常一样用着电脑，屏幕右下角弹出一个再熟悉不过的提示：Windows 更新已就绪，需要重启完成安装。我随手点了“更新并重启”，心里想的不过是等几分钟，喝口水，回来继续干活。

我万万没想到，这个看似平常的点击，差点让我以为电脑彻底废了。

重启之后，屏幕没有出现熟悉的 Windows 徽标，而是冷冷地甩出一行字：

**No boot device.**

我愣了一下。第一反应是：不会吧？硬盘坏了？可这台笔记本平时用得好好的，没摔没碰，怎么说没启动设备就没启动设备了？

我赶紧强制关机，再开机，反复按 F2 进 BIOS。好在，BIOS 里清清楚楚地识别到了硬盘——**铠侠 512G**，型号、容量都在。看到硬盘还在，我稍微松了口气：硬件没坏，那问题应该出在软件层面。

可接下来的情况，远比我想的折磨人。

退出 BIOS，电脑并没有进入系统，而是转了一圈，又自动回到了 BIOS 界面。再退，再进；再退，再进。像个死循环。我长按电源键强制关机，重新开机，还是老样子。那一刻，我开始意识到，这不是简单的“启动顺序错了”，而是系统引导被这次更新搞坏了。

更让人崩溃的是，我想进 Windows 恢复环境（WinRE）修复，却根本进不去。按照网上说的“开机看到徽标就强制关机，重复三次”，我试了；连续点 F8，我试了；笔记本自带的恢复快捷键，我也试了。结果不是直接进 BIOS，就是黑屏，连恢复界面的影子都没见着。

那会儿我是真的火了。电脑满电，硬盘能识别，偏偏系统进不去，恢复环境也打不开，手里还没有第二台电脑可以做启动 U 盘。那种感觉就像：明明知道问题不大，却被堵在门外，怎么敲都没人应。

冷静下来之后，我重新梳理了所有线索：**更新后出现、硬盘能被 BIOS 识别、Secure Boot 开启、系统反复回 BIOS、恢复快捷键失效**。这些信息拼在一起，指向了一个容易被忽略的地方——**BIOS 里的安全启动（Secure Boot）**。

有不少笔记本用户遇到过类似情况：系统更新后，Secure Boot 会拦截更新过的引导程序，导致电脑找不到可启动的系统，同时也会让部分恢复功能失效。换句话说，不是系统没救，而是 BIOS 把“门”锁死了。

于是我再次开机进 BIOS，找到 `Security` 选项卡，把 **Secure Boot** 从 `Enabled` 改成了 `Disabled`，按 F10 保存退出。

这一次，屏幕没有再回到 BIOS。

它显示出了“正在更新，请勿关闭电脑”，进度停在了 **30%**。正是之前那次没跑完的更新。电脑开始继续安装，随后自动重启。一次，两次，黑屏，转圈，再重启。我盯着屏幕，连大气都不敢出，生怕哪一步又回到那个该死的 BIOS 界面。

好在，更新进度一点点走完，系统终于正常启动了。

看到桌面出现的那一刻，我整个人像打完一场仗一样瘫在椅子上。从“No boot device”到反复卡 BIOS，从进不去 WinRE 到恢复快捷键失效，折腾了大半天，最后居然只是关闭 Secure Boot 就让系统把更新补完了。

这次经历给我上了很实在的一课：**系统更新后开不了机，不一定硬盘坏了，也不一定要立刻做启动 U 盘。先看 BIOS 能不能识别硬盘；如果能，再想想是不是 Secure Boot 在作怪。** 对部分笔记本来说，更新后引导被安全启动拦截的情况并不少见。

当然，更重要的教训是：以后看到“更新并重启”，别手太快。先暂停更新、备份重要文件，等哪天不赶时间了再让它折腾。毕竟，一次看似普通的升级，真有可能变成一场惊心动魄的深夜救援。
